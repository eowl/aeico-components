Aeico is a lightweight Web Components framework for building UI libraries without heavy dependencies. Run npm install aeico then import the components you need from the package. Yes. Web Components work in any framework — React, Vue, Angular, Svelte — or plain HTML.
Multiple sections can be expanded at the same time when the multiple attribute is set. Each ae-detail retains its own open/close state independently. You can still close individual panels by clicking their header.
Content inside an outlined detail group. All items share the same visual border chain. The outer corners stay rounded while inner edges meet flush.
Each item can still carry its own color independently. Mix and match colors per item as needed. Falls back to the default style.
All items inherit variant="outlined" from the group. No need to set variant on each child individually. Per-item overrides still work when the group has no setting. Group sets both variant="faint" and color="primary". Every child receives the same visual treatment.
When there is only one item the full border radius is kept on all four corners.
